## 🚧 Featured Project

### [MatchMode – Distributed Multiplayer Backend Platform](https://github.com/stokesgarrett/matchmode)

A production-style distributed backend built from scratch using Java and Spring Boot. Designed around real-world engineering principles: microservices, event-driven communication, and containerized local development.

**What's being built:**
- JWT-based authentication with BCrypt password hashing
- Matchmaking queue and session lifecycle management
- WebSocket-based real-time session handling
- Event-driven service communication via Redis Streams
- Relational data modeling with PostgreSQL
- Fully Dockerized with Docker Compose

**Stack:** Java · Spring Boot · PostgreSQL · Redis · Docker · React + Vite
